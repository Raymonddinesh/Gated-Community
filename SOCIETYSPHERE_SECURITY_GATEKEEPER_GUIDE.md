# SOCIETYSPHERE — SECURITY GATEKEEPER & GUARD GUIDE

**Target Audience**: Security Personnel, Gatekeepers, and Control Room Operators  

---

## 1. GATEKEEPER TERMINAL LOGIN
1. Open the Security Terminal app on your gate tablet or workstation.
2. Login using your Security User credentials assigned by the society administrator.
3. Verify your gate location (Main Gate 1, Service Gate 2, etc.).

---

## 2. VISITOR CHECK-IN & PRE-APPROVED PASSES
- **Pre-Approved Visitor**: Ask the visitor for their 6-digit invitation code or QR code. Enter the code in the terminal to view pre-approved resident details and click **Approve Entry**.
- **Walk-in Visitor**: Enter visitor name, mobile number, vehicle number, purpose, and host unit number. The system will send an instant push notification to the resident for approval.

---

## 3. VEHICLE VERIFICATION
- Scan vehicle RFID tag / license plate or manually enter plate number.
- Verify active sticker status (`VERIFIED` vs `UNREGISTERED`).
- Report unauthorized or blacklisted vehicles.

---

## 4. EMERGENCY PROCEDURES
- If an emergency SOS is triggered by a resident, the gate terminal will sound an alert and display the unit location and nature of emergency (Fire, Medical, Security, Lift Entrapment).
- Immediately dispatch field guards and contact emergency services.
